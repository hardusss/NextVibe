# CLOCK IN Hackathon Changelog (Sep 8 – Oct 8, 2026)

All work below was built during the hackathon window. Format: date · scope · summary · key files.

## 2026-09-09
- fix(frontend): MintBottomSheet — Reanimated-only animations, zero text scaling to eliminate rasterization/pixelation on iOS/Android, shimmering track fill during minting, rewritten SwipeToCollect with proper Gesture Handler offsets (`activeOffsetX(8)`, `failOffsetY([-14, 14])`, pull-to-dismiss sheet pan, single-fire haptic at 85%), and wrapped in `GestureHandlerRootView` across all render paths. Files: `frontend/NextVibe/components/NftClaim/MintBottomSheet/{index.tsx,SwipeToCollect.tsx,useCollectFlow.ts,HeroCard.tsx}`
- perf(backend): respond immediately on collect and offload author push notification to background daemon thread via `transaction.on_commit`; store deterministic `asset_id` on `PendingClaim` during prepare; added `python manage.py backfill_asset_ids` management command to resolve historic unparsed cNFT records. Files: `backend/NextVibeAPI/posts/view_pac/collect.py`, `posts/models.py`, `posts/management/commands/backfill_asset_ids.py`
- perf(nft-service): deterministic asset id via tree `numMinted` PDA derivation under in-process mutex `withMintLock`, `skipPreflight: true` broadcast, dropped the 6-retry delay parse loop in favor of instant response & single-shot confirmed parse; added `POST /asset-id-from-signature` endpoint. End-to-end collect time dropped from ~10–12s to ≤1.8s on iOS and ≤3.5s on MWA. Files: `nft-service/src/index.ts`
- fix(frontend): collect flow selects signer by platform; iOS and passkey users use gasless path, Android+MWA signs memo via Seed Vault; logger dumps raw wallet errors. Backend defensively downgrades `signer:"mwa"` to `"none"` for non-Android clients via the new `X-Client-Platform` header (+ test). Files: `frontend/NextVibe/components/NftClaim/MintBottomSheet/useCollectFlow.ts`, `src/utils/walletLogger.ts`, `src/api/collect.ts`, `backend/NextVibeAPI/posts/view_pac/collect.py`, `posts/tests/test_collect.py`
- chore(all): end-to-end diagnostic logging for the cNFT mint/collect flow — Django `posts.collect` logger (INFO console config in settings) logs every prepare/submit/publish request, every rejection with its error code + user/post context, edition reservations, nft-service failures with bodies, finalization, rep bonus, and push outcomes; nft-service logs timestamped structured events for all endpoints (request, metadata, build/hash, signature verification failures with signer index, send/confirm timing, parse retries, done) and `/mint` now returns clean `{success:false,error}` instead of crashing; frontend `useCollectFlow` logs each flow phase (prepare/sign/submit, silent expiry retry, cancel, mapped errors) via `walletLogger` under a new `Collect:Flow` tag. Serialized transactions are never logged. Files: `backend/NextVibeAPI/{NextVibeAPI/settings.py,posts/view_pac/{collect,mint_nft}.py}`, `nft-service/src/index.ts`, `frontend/NextVibe/{components/NftClaim/MintBottomSheet/useCollectFlow.ts,src/utils/walletLogger.ts}`
- docs(nft-service): README documenting all four endpoints (`/mint`, `/mint/og`, `/collect/prepare`, `/collect/submit`), the user-signed memo mechanism, env vars, and logging policy. Files: `nft-service/README.md`
- test(backend): collect flow test suite — daily-limit boundary, distinct editions for concurrent prepares, IRL reservation enforced/lifted around the 24h window, collect rep bonus excluded from eligibility, claim expiry (410), submit finalization, signer:"none" legacy mint, already-claimed/sold-out/owner guards (12 tests, all passing on sqlite). Removed the stub `posts/tests.py` that shadowed the `posts/tests/` package so the suite is discoverable. Files: `backend/NextVibeAPI/posts/tests/{__init__.py,test_collect.py}`
- chore(repo): add hackathon changelog to track all CLOCK IN work. Files: `CHANGELOG-hackathon.md`
- feat(nft-service): two-phase user-signed free collect — `POST /collect/prepare` builds a gasless mint tx (backend fee payer) with an SPL Memo instruction requiring the collector's signature and partial-signs it; `POST /collect/submit` verifies the message hash and all required signatures, broadcasts, confirms, and parses the cNFT asset ID. Files: `nft-service/src/index.ts`
- feat(frontend): free collect flow — new `src/api/collect.ts` (prepare/submit with typed error codes) and `NftClaim/useCollectFlow.ts` state machine (prepare → MWA `signTransactions` → submit, one silent retry on expiry, LazorKit fallback via signer:"none", owner publish path); MintBottomSheet stripped of all pricing UI ("≈ free (network fee only)", edition counter, IRL reservation note, mapped error copy); SOL-transfer payment builder deleted; feed/detail/profile screens rewired to `collect`/`onCollected`. Files: `frontend/NextVibe/src/api/{collect,mint.nft}.ts`, `components/NftClaim/{MintBottomSheet.tsx,ButtonCollect.tsx,useCollectFlow.ts}`, `components/{Home/MainPage.android.tsx,Home/MainPage.ios.tsx,PostDetails/PostDetailsScreen.tsx,ProfilePage/PostModal.tsx,Events/AddLumaEventSheet.tsx}`, `src/types/post.ts` (removed `hooks/buildPaymentInstructions.ts`)
- feat(frontend): MintBottomSheet redesigned as a collect-card experience — tilted floating hero card with gradient border/glow that flips to a shimmer back while minting, 50-dot edition strip (minted/IRL-reserved/free, pulsing upcoming edition), "what you get" pills, gradient swipe track with "Release to collect", success particle burst + count-up chip + haptics, "View in wallet"/"Done" actions, `reduceMotion` respected; refactored into `NftClaim/MintBottomSheet/` (index, HeroCard, EditionStrip, SwipeToCollect, SuccessBurst, useCollectFlow). Files: `frontend/NextVibe/components/NftClaim/MintBottomSheet/*`, caller screens updated for `creatorAvatar`
- feat(backend): free collect endpoints — `PendingClaim` model reserves editions for in-flight claims; `POST /posts/collect/prepare/` enforces wallet/ownership/duplicate checks, a 10-claims-per-UTC-day limit, 50-edition supply cap, and a 24h IRL reservation of editions 2–11 (networking tap or event check-in with the author); `POST /posts/collect/submit/` finalizes the user-signed mint, awards +2 rep to IRL-connected claimers, and pushes the author. Owner publish path (`cnft-mint/`) stripped of price/payment handling; post serializers now expose a `collect` object and no longer serialize prices. Files: `backend/NextVibeAPI/posts/{models,constants,urls}.py`, `posts/src/collect_{eligibility,memo}.py`, `posts/view_pac/{collect,mint_nft,get_post,recommendation_feed}.py`, `posts/serializers_pac/recommendation_feed_serializer.py`
